ApplicationGroup

k8s.gitops.nyl/v1

Rendered GitOps Resources · Download JSON Schema · Usage guide

Selects Kubernetes Releases and defines their Argo CD Application, project, and namespace policies.

Literal metadata labels participate in target selection; the spec is rendered afterward. This is compiler configuration, not a workload manifest.

When needed

Required to select Release entry files and generate their workload Applications in rendered GitOps.

If omitted

Nyl does not infer groups from directories or Release files. Without a selected, enabled ApplicationGroup, a target emits no workload Applications. Direct file rendering does not require an ApplicationGroup.

Example

apiVersion: k8s.gitops.nyl/v1
kind: ApplicationGroup
metadata:
  name: workloads
spec:
  applicationNamespace: argocd
  destinationNamespace: workloads
  projectTemplate:
    destinations:
      - namespace: workloads
        server: https://kubernetes.default.svc
  source:
    path: applications/workloads

Unknown fields are rejected.

metadata.name

Required · string

Project-local identity. Must be a Kubernetes DNS subdomain and remain static during discovery.

spec

Required · object

Configuration for this resource.

Unknown fields are rejected.

Choose exactly one variant:

  • projectRef — Uses the named AppProjectDefinition, so the project can be shared between groups or managed outside Nyl.
  • projectTemplate — Generates an AppProject for this group from the declared AppProject fields; omitted fields admit only what the group deploys.
  • Neither — Generates an AppProject named after the group that admits only what it deploys: the target publication repository, the target Cluster with the group’s Release namespaces, and the resource kinds it renders.

spec.applicationDeletionPolicy

Optional · string

Argo CD Application finalizer policy: foreground cascade, background cascade, or orphan workloads.

default: "Foreground"

Allowed values:

ValueMeaning
"Foreground"Cascade deletion in the foreground using the Argo CD resources finalizer.
"Background"Cascade deletion in the background using the Argo CD background finalizer.
"Orphan"Omit the finalizer and leave workload resources in place.

spec.applicationNameTemplate

Optional · string or null

Generated workload Application name, as a template value expanded once per Release. It must contain at least one ${ expression }, evaluated with the target context plus release, the rendered Release; $${ writes a literal ${, and all other text, including {{ … }}, is literal. Defaults to the Release name; use target-qualified names such as ${ target.metadata.name }-${ release.metadata.name } when targets share an Argo CD namespace.

spec.source

Optional · object or null

Release source selection. Omission derives applications/<group-name> for central groups or the containing directory for _application-group.yaml.

Unknown fields are rejected.

Choose exactly one variant:

  • repositoryRef — Reads Releases from a checkout of the named GitRepository.
  • repository — Reads Releases from a checkout of the inline coordinates declared here.
  • Neither — Reads Releases from this project, at the declared path.
