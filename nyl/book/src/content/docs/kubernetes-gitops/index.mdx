Kubernetes GitOps publishes rendered manifests to Git for a reconciler to sync.
Nyl compiles each deployment target into an ordinary directory of Kubernetes
manifests in a Git revision, with Argo CD Applications and least-privilege
AppProjects. Argo CD, Flux, or another reconciler syncs the published YAML, and
Nyl never runs in the cluster's reconciliation path.

This layer builds on [Kubernetes Rendering](/nyl/kubernetes-rendering/): the
same configuration renders the manifests, so what you inspect locally is what CI
publishes.
