Rendered GitOps Resources

Configuration resources of the rendered manifest pattern. They are compiler inputs that render-tree reads, not objects installed in a cluster.

Resources

Each reference explains when to declare the resource, what happens if it is omitted, and every field.

  • Shared GitOps gitops.nyl/v1
    • GitRepository: Names reusable, credential-free Git read and publication coordinates.
  • Kubernetes GitOps k8s.gitops.nyl/v1
    • DeploymentTarget: Binds a Kubernetes Cluster to render values, ApplicationGroup selection, and Git publication coordinates.
    • ArgoCDInstance: Defines an Argo CD control plane and the catalog defaults for its deployment targets.
    • ApplicationGroup: Selects Kubernetes Releases and defines their Argo CD Application, project, and namespace policies.
    • AppProjectDefinition: Defines an Argo CD AppProject manifest or an externally managed project contract.

The resources guide explains their shared envelope, discovery, and validation.
