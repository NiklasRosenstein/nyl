Reference/Terraform

Terraform

units.gitops.nyl/v1

Orchestration Resources · Download JSON Schema · Usage guide

A Terraform or OpenTofu infrastructure unit, preserving native state and locks.

Example

apiVersion: units.gitops.nyl/v1
kind: Terraform
metadata:
  name: workloads
spec:
  backend:
    bucket: acme-state
    key: production/network
  outputs:
    id:
      type: string
  source:
    path: infra/network
  variables:
    region: eu-west-1

Optional · boolean
